# TOOLS

## 1\. Selenium

- Ferramenta de automação para testes de aplicações web, permitindo simular interações do usuário com navegadores e validar o funcionamento da aplicação.
- Ideal para testes de interface de usuário (UI) de aplicações web.
- Suporta diferentes navegadores, como Chrome, Firefox e Edge.
- Oferece suporte a linguagens de programação como Java, Python, C# e JavaScript.

## 2\. Postman

- Ferramenta para desenvolvimento, teste e automação de APIs, permitindo enviar requisições HTTP, validar respostas e verificar o comportamento dos serviços.
- Oferece uma interface para criar, enviar e validar solicitações HTTP (GET, POST, PUT e DELETE).
- Permite criar coleções de requisições e organizar testes de APIs.
- Possibilita automatizar testes e integrar sua execução a pipelines de CI/CD.

## 3\. RestAssured

- Biblioteca Java utilizada para automatizar testes de APIs RESTful, facilitando o envio de requisições e a validação de respostas diretamente em testes automatizados.
- Permite automatizar chamadas HTTP diretamente no código Java.
- Facilita a validação de códigos de status, cabeçalhos e conteúdo das respostas.
- Integra-se a frameworks de teste Java, como JUnit e TestNG.

## 4\. JMeter

- Ferramenta de testes de desempenho que permite avaliar a performance, a estabilidade e a capacidade de aplicações, APIs e serviços sob diferentes níveis de carga.
- Simula múltiplas requisições simultâneas para medir a performance de serviços RESTful e SOAP.
- Permite realizar testes de carga, estresse e capacidade.
- Gera relatórios e métricas sobre tempos de resposta, vazão e erros durante os testes.

## 5\. SoapUI

- Ferramenta para testes funcionais, de desempenho e de segurança em web services SOAP e REST, permitindo validar requisições, respostas e o comportamento dos serviços.
- Fornece uma interface visual para criar e executar testes de APIs.
- Permite validar respostas, códigos de status, estruturas de dados e regras de negócio.
- Oferece recursos para automatizar testes e executar sequências de validações.

## 6\. Cucumber

- Ferramenta de automação baseada em BDD (Behavior-Driven Development), que permite descrever cenários de teste em linguagem natural e conectá-los a implementações automatizadas.
- Usa a linguagem Gherkin para descrever cenários de teste em formato legível por humanos.
- Facilita a comunicação entre desenvolvedores, testadores e profissionais de negócio.
- Pode ser integrado a ferramentas de automação, como Selenium e RestAssured.

## 7\. K6

- Ferramenta de testes de desempenho voltada para APIs e aplicações web, permitindo simular múltiplos usuários e avaliar métricas como tempo de resposta, vazão e taxa de erros.
- Permite criar scripts de teste em JavaScript para definir cenários de carga.
- Oferece suporte a testes de carga, estresse e verificação de limites de desempenho.
- Integra-se a pipelines de CI/CD e permite acompanhar métricas para identificar problemas de performance.

## 8\. Cypress

- Framework de automação de testes para aplicações web, utilizado principalmente em testes end-to-end e de componentes, permitindo validar funcionalidades e interações diretamente no navegador.
- Oferece recursos para simular ações do usuário e verificar elementos da interface.
- Permite executar testes de forma interativa, facilitando a identificação e a depuração de falhas.
- Suporta testes automatizados com JavaScript e TypeScript.

## 9\. Playwright

- Framework de automação de testes para aplicações web que oferece suporte a diferentes navegadores, permitindo executar testes end-to-end, validar funcionalidades e simular interações dos usuários.
- Suporta navegadores como Chromium, Firefox e WebKit.
- Permite realizar testes em diferentes navegadores, dispositivos e tamanhos de tela.
- Oferece recursos para execução paralela, captura de screenshots, gravação de vídeos e integração com pipelines de CI/CD.
