QA TOOLKIT / 009
Ferramentas fundamentais

O Arsenal
do QA

Nove ferramentas que fazem parte do universo de qualidade de software. Da automação de interfaces aos testes de APIs, passando por BDD e performance, cada tecnologia tem um papel específico na construção de aplicações mais confiáveis.

UI / E2E API Testing Performance BDD
TOOL / 01 UI AUTOMATION

Selenium

Ferramenta de automação de testes web que simula interações do usuário com navegadores para validar o funcionamento das aplicações.

  • Ideal para testes de interface de usuário (UI).
  • Suporta Chrome, Firefox, Edge e outros navegadores compatíveis.
  • Oferece suporte a Java, Python, C# e JavaScript, entre outras linguagens e bindings.
Principal aplicação Testes automatizados de navegador
TOOL / 02 API TESTING

Postman

Plataforma para desenvolvimento e testes de APIs, permitindo enviar requisições HTTP, validar respostas e verificar o comportamento de serviços.

  • Cria e envia requisições GET, POST, PUT e DELETE.
  • Organiza requisições em coleções e permite criar testes automatizados.
  • Integra execuções automatizadas a pipelines de CI/CD.
Principal aplicação Desenvolvimento e validação de APIs
TOOL / 03 JAVA / API

RestAssured

Biblioteca Java que simplifica a automação de testes de APIs RESTful, integrando requisições HTTP e validações diretamente ao código de teste.

  • Automatiza chamadas HTTP dentro de testes Java.
  • Valida códigos de status, cabeçalhos e conteúdo das respostas.
  • Integra-se a frameworks como JUnit e TestNG.
Principal aplicação Testes de API com Java
TOOL / 04 PERFORMANCE

JMeter

Ferramenta de testes de desempenho utilizada para avaliar a performance, estabilidade e capacidade de aplicações, APIs e serviços sob diferentes níveis de carga.

  • Simula múltiplas requisições simultâneas em serviços REST e SOAP.
  • Permite realizar testes de carga, estresse e capacidade.
  • Gera métricas de tempo de resposta, vazão e erros.
Principal aplicação Desempenho e testes de carga
TOOL / 05 WEB SERVICES

SoapUI

Ferramenta para testes funcionais e de desempenho em web services SOAP e REST, com recursos visuais para criação e execução de cenários de teste.

  • Permite criar e executar testes de APIs por uma interface visual.
  • Valida respostas, status HTTP, estruturas de dados e regras de negócio.
  • Oferece recursos para automatizar sequências de validações.
Principal aplicação Testes funcionais de serviços SOAP e REST
TOOL / 06 BDD

Cucumber

Ferramenta de automação baseada em Behavior-Driven Development (BDD), que conecta cenários descritos em linguagem legível a implementações automatizadas.

  • Utiliza Gherkin para descrever cenários em formato legível por humanos.
  • Facilita a comunicação entre QA, desenvolvimento e negócio.
  • Pode ser integrado a ferramentas como Selenium e RestAssured, conforme a configuração do projeto.
Principal aplicação Cenários de negócio e BDD
TOOL / 07 LOAD TESTING

k6

Ferramenta de testes de desempenho voltada para APIs e aplicações web, utilizada para simular carga e analisar tempo de resposta, vazão e taxa de erros.

  • Permite criar cenários de teste com scripts JavaScript.
  • Suporta testes de carga e avaliação dos limites de desempenho.
  • Integra-se a pipelines de CI/CD e permite definir limites de aprovação por métricas.
Principal aplicação Performance automatizada em pipelines
TOOL / 08 E2E / COMPONENTS

Cypress

Framework de automação para aplicações web, utilizado principalmente em testes end-to-end e de componentes, validando funcionalidades e interações no navegador.

  • Simula ações do usuário e verifica elementos da interface.
  • Oferece execução interativa e ferramentas de depuração.
  • Suporta testes automatizados com JavaScript e TypeScript.
Principal aplicação Testes web e de componentes
TOOL / 09 CROSS-BROWSER

Playwright

Framework de automação web que permite executar testes end-to-end em diferentes navegadores e validar funcionalidades por meio de interações automatizadas.

  • Suporta Chromium, Firefox e WebKit.
  • Permite testar diferentes dispositivos e tamanhos de tela.
  • Oferece execução paralela, screenshots, gravação de vídeos e integração com CI/CD.
Principal aplicação Testes E2E em múltiplos navegadores
TOOL / 09 AUTOMAÇÃO DE TESTES

Robot Framework

Framework de automação de testes baseado em palavras-chave (keyword-driven), que permite automatizar testes funcionais, de aceitação e end-to-end, utilizando uma sintaxe simples e legível.

  • Possui sintaxe baseada em palavras-chave e utiliza arquivos de teste legíveis.
  • Permite automação web com SeleniumLibrary e Browser Library, baseada em Playwright.
  • Oferece relatórios, logs detalhados, reutilização de keywords e integração com CI/CD.
Principal aplicação Automação de testes funcionais e E2E
