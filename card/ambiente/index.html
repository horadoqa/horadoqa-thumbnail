AMBIENTE / 01 DEV

Desenvolvimento Development

Objetivo

Criar, implementar e testar novas funcionalidades durante o desenvolvimento do sistema.

Características
  • Utilizado principalmente pela equipe de desenvolvimento.
  • Código em constante modificação.
  • Permite testes unitários e de integração.
  • Dados podem ser fictícios ou simulados.
  • Maior liberdade para alterações e experimentações.
Resumo

É onde as funcionalidades são criadas, corrigidas e testadas antes de seguir para validação.

AMBIENTE / 02 STAGING

Homologação Staging / Teste

Objetivo

Validar se as funcionalidades estão corretas antes da publicação em produção.

Características
  • Ambiente semelhante ao de produção.
  • Utilizado por QA e responsáveis pela validação.
  • Testes funcionais, integrados e de aceitação.
  • Identificação de erros antes da liberação.
  • Aprovação das funcionalidades para publicação.
Resumo

É a última barreira de validação antes que a mudança chegue aos usuários finais.

AMBIENTE / 03 PROD

Produção Production

Objetivo

Disponibilizar o sistema para uso dos usuários finais em operação real.

Características
  • Ambiente oficial acessado pelos usuários.
  • Contém dados reais.
  • Exige disponibilidade, segurança e desempenho.
  • Alterações são controladas e planejadas.
  • Monitoramento contínuo para garantir estabilidade.
Resumo

É a versão oficial do sistema. Mudanças devem ser realizadas com cautela para evitar impactos no negócio.
