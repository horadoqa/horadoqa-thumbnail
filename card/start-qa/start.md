# Start QA

Olá! 👋

Recentemente, passei algumas sugestões de estudo para uma pessoa que está começando na área de Qualidade de Software (QA) e resolvi compartilhar aqui também.

Se você está começando na área, minha recomendação é seguir uma sequência de aprendizado, construindo uma boa base antes de partir para a automação de testes.

📌 1. Fundamentos de HTTP
Entender como funcionam os métodos HTTP é um ótimo ponto de partida, principalmente para quem pretende trabalhar com testes de APIs e aplicações web.
🎥 https://lnkd.in/dnkYtztT

📌 2. Testes Manuais
Depois, avance para os testes manuais. Aprenda a analisar cenários, elaborar casos de teste, identificar falhas e validar se o software atende aos requisitos.
🎥 https://lnkd.in/dRHUQzq6

📌 3. Testes Automatizados
Com uma boa base em testes, você pode começar a explorar as ferramentas de automação. 

Minha sugestão é conhecer as opções abaixo e, inicialmente, escolher uma delas para praticar:
- Cypress: https://lnkd.in/dv5C8Hwq
- Robot Framework: https://lnkd.in/diJCjaXF
- Playwright: https://lnkd.in/dYJad-JQ

🎯 Uma dica importante: não tente aprender tudo de uma vez. Estude os fundamentos, pratique bastante e avance aos poucos. A consistência faz diferença!

Todo esse conteúdo está disponível no meu canal, Hora do QA, onde compartilho conhecimentos e dicas para quem quer desenvolver suas habilidades na área de Qualidade de Software.

Se tiver dúvidas, pode perguntar! Será um prazer ajudar. 🚀
