Processo de
Testes de Software

Sete etapas fundamentais para organizar a qualidade do software, reduzir riscos e tornar as entregas mais rápidas, previsíveis e confiáveis.

ETAPA / 01 DISCOVERY

Análise de Requisitos

  • Entender os requisitos
  • Identificar requisitos testáveis
  • Entender as necessidades do usuário e definir o escopo de testes
ETAPA / 02 STRATEGY

Planejamento de Testes

  • Estratégia de testes
  • Alocação de recursos
  • Identificação de riscos
ETAPA / 03 DESIGN

Desenvolvimento de Casos de Teste

  • Criação de cenários de teste
  • Escrita dos casos de testes
  • Preparação de dados de testes
ETAPA / 04 ENVIRONMENT

Configuração do Ambiente de Testes

  • Provisionar dados e infraestrutura de teste
  • Automatizar configuração do ambiente
  • Gerenciar acessos e versões do ambiente
ETAPA / 05 EXECUTION

Execução de Testes

  • Executar casos de teste
  • Registrar e acompanhar defeitos
  • Testes de regressão
ETAPA / 06 REPORT

Relatório de Testes

  • Documentar resultados dos testes
  • Métricas de defeitos
  • Principais aprendizados dos testes
ETAPA / 07 CLOSURE

Encerramento de Testes

  • Relatórios finais de teste
  • Lições aprendidas
  • Arquivamento dos artefatos de teste
