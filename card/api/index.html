Conceito fundamental

O que é
uma API?

API é uma forma padronizada de permitir que diferentes sistemas conversem entre si. Ela define como uma aplicação pode solicitar informações ou executar ações em outra aplicação, sem precisar conhecer como ela foi construída internamente.

CONCEITO / 01 INTERFACE

API Application Programming Interface

Uma API é uma interface de comunicação entre sistemas. Ela disponibiliza regras e operações que permitem que uma aplicação solicite dados ou serviços de outra.

CONCEITO / 02 REQUEST

Requisição request

É o pedido enviado para a API. A aplicação informa o que deseja fazer, utilizando métodos como GET, POST, PUT ou DELETE, além de parâmetros, cabeçalhos e, quando necessário, um corpo com dados.

CONCEITO / 03 RESPONSE

Resposta response

É o retorno da API depois que uma requisição é processada. A resposta normalmente contém um código de status, cabeçalhos e, quando aplicável, os dados solicitados ou informações sobre o resultado da operação.

CONCEITO / 04 PURPOSE

Para que serve? integration

Uma API serve para integrar sistemas e compartilhar funcionalidades ou dados. Aplicativos, sites, sistemas internos e serviços externos podem se comunicar sem precisar acessar diretamente o banco de dados ou o código interno uns dos outros.

Como uma API funciona
Cliente Aplicação que precisa de uma informação ou deseja executar uma ação.
→
API Recebe a requisição, aplica regras e encaminha o processamento necessário.
→
Servidor Processa a operação e devolve uma resposta para o cliente.
Exemplo / 01

Consultar um usuário

Um aplicativo precisa mostrar os dados de um usuário. Em vez de acessar diretamente o banco de dados, ele envia uma requisição para a API.

GET /usuarios/123

O que o QA verifica?

O QA pode validar se a API retorna o status correto, os dados esperados, mensagens de erro adequadas, regras de negócio, autenticação e comportamento para diferentes entradas.
