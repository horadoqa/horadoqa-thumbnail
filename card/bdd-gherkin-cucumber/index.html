Conceitos fundamentais

BDD, Gherkin
& Cucumber

Três conceitos que aparecem juntos no desenvolvimento orientado a comportamento. Entenda o que é BDD, como o Gherkin descreve os comportamentos esperados e como o Cucumber transforma essas especificações em testes automatizados.

CONCEITO / 01 APPROACH

BDD behavior

Behavior-Driven Development é uma abordagem de desenvolvimento que utiliza o comportamento esperado do sistema como ponto de partida. O objetivo é criar uma linguagem comum entre negócio, desenvolvimento e QA, descrevendo o que o sistema deve fazer a partir da perspectiva do usuário.

CONCEITO / 02 LANGUAGE

Gherkin syntax

É uma linguagem estruturada e legível por humanos usada para escrever cenários de comportamento. Ela utiliza palavras-chave como Feature, Scenario, Given, When e Then, permitindo transformar requisitos em exemplos claros e compartilhados entre pessoas técnicas e não técnicas.

CONCEITO / 03 AUTOMATION

Cucumber framework

É uma ferramenta que interpreta os cenários escritos em Gherkin e permite conectá-los a código de automação. Cada passo do cenário pode ser associado a uma implementação que executa ações e verifica resultados, transformando a especificação em um teste automatizado.

CONCEITO / 04 CONNECTION

Como se relacionam? workflow

Os conceitos se complementam: BDD define a abordagem, Gherkin descreve o comportamento e Cucumber executa a especificação. Em outras palavras: o BDD orienta a forma de pensar, o Gherkin registra os exemplos e o Cucumber ajuda a automatizar esses exemplos como testes.
