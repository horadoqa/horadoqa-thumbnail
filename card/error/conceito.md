As Diferenças Conceituais

- Erro (Engano / Mistake): É uma ação humana incorreta. Acontece quando o desenvolvedor ou analista comete um equívoco de lógica, entende mal um requisito ou digita uma instrução errada.

- Defeito (Bug / Fault): É a materialização do erro dentro do artefato (código-fonte, documentação ou arquitetura). É o ponto exato do sistema implementado de maneira incorreta. Se o código com defeito nunca for executado, ele pode ficar latente sem ser percebido.

- Falha (Failure): É o comportamento indesejado ou divergente do esperado que se manifesta quando o software está em execução. Ocorre quando o defeito é ativado e o usuário (ou o sistema de teste) percebe que o resultado difere do planejado.

- Bug: É o termo informal e popular ("apelido carinhoso") usado no cotidiano para se referir a qualquer anomalia, defeito ou comportamento incorreto encontrado em um sistema de hardware ou software.
