Conceitos fundamentais

As Diferenças
Conceituais

Quatro termos que aparecem diariamente no universo de qualidade de software — mas que representam momentos diferentes entre o equívoco humano e o comportamento observado no sistema.

CONCEITO / 01 HUMAN

Erro mistake

É uma ação humana incorreta. Acontece quando o desenvolvedor ou analista comete um equívoco de lógica, entende mal um requisito ou digita uma instrução errada.

CONCEITO / 02 ARTIFACT

Defeito bug / fault

É a materialização do erro dentro do artefato — código-fonte, documentação ou arquitetura. É o ponto exato do sistema implementado de maneira incorreta. Se o código com defeito nunca for executado, ele pode ficar latente sem ser percebido.

CONCEITO / 03 RUNTIME

Falha failure

É o comportamento indesejado ou divergente do esperado que se manifesta quando o software está em execução. Ocorre quando o defeito é ativado e o usuário ou o sistema de teste percebe que o resultado difere do planejado.

CONCEITO / 04 COMMON TERM

Bug informal

É o termo informal e popular usado no cotidiano para se referir a qualquer anomalia, defeito ou comportamento incorreto encontrado em um sistema de hardware ou software.
