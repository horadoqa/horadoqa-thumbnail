Desenvolvimento orientado a comportamento

O que é
BDD?

Uma abordagem que coloca o comportamento esperado do produto no centro da conversa, aproximando negócio, desenvolvimento e qualidade para construir o software certo.

CONCEITO / 01 APPROACH

Behavior-Driven Development BDD

BDD significa Behavior-Driven Development, ou Desenvolvimento Orientado a Comportamento. É uma abordagem que descreve o software a partir de comportamentos observáveis e relevantes para o negócio.

CONCEITO / 02 COLLABORATION

Três amigos team

BDD incentiva a colaboração entre negócio, desenvolvimento e QA. O objetivo é construir um entendimento compartilhado sobre o que o sistema precisa fazer antes de transformar esse entendimento em código.

CONCEITO / 03 BEHAVIOR

Comportamento observable

O foco não está em testar detalhes internos da implementação. A pergunta principal é: “Dado este contexto, quando esta ação acontecer, qual resultado esperamos?”

CONCEITO / 04 VALUE

Menos ambiguidade shared language

Ao discutir exemplos concretos antes da implementação, a equipe consegue identificar ambiguidades, alinhar expectativas e descobrir regras de negócio mais cedo.

O fluxo do BDD
01 / DISCUTIR

Exemplos

Negócio, QA e desenvolvimento conversam sobre exemplos reais do comportamento esperado.

02 / DESCREVER

Cenários

Os exemplos são transformados em cenários claros, geralmente utilizando a linguagem Gherkin.

03 / ENTREGAR

Software

Os cenários orientam a implementação e podem posteriormente ser automatizados como testes.
