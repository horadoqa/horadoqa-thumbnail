REFERÊNCIA / 01 CLI COMMANDS

Do setup à execução

Consulte a sequência de comandos, sua finalidade e quando utilizá-los durante a configuração e execução dos testes.

Etapa Comando Descrição
01 node -v Verifica a versão instalada do Node.js e ajuda a confirmar se ele está disponível no terminal.
02 npm init -y Inicializa o projeto e cria o arquivo package.json com as configurações padrão.
03 npm install cypress --save-dev Instala o Cypress como dependência de desenvolvimento e registra o pacote no projeto.
04 npx cypress open Abre a interface gráfica do Cypress para configurar, selecionar e acompanhar testes de forma interativa.
05 npx cypress run Executa os testes pelo terminal, geralmente sem abrir a interface gráfica. É útil em pipelines de CI/CD.
06 npm test Executa o script test configurado no package.json. Para rodar o Cypress, adicione "test": "cypress run" à seção "scripts".
Regra dos arquivos de teste

Por padrão, os arquivos de teste JavaScript do Cypress utilizam a extensão .cy.js.
Exemplos: login.cy.js e cadastro.cy.js.

O Cypress identifica esses arquivos conforme os padrões de descoberta definidos na configuração do projeto. Mantenha os testes no diretório esperado, normalmente cypress/e2e.
