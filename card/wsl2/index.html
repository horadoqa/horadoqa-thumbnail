Fundamentos de WSL2

WSL2 com Ubuntu 26.04 —
Do Windows ao Linux.

O Windows Subsystem for Linux 2 (WSL2) permite executar um ambiente Linux integrado ao Windows, sem a necessidade de configurar uma máquina virtual tradicional manualmente. Com o Ubuntu 26.04 LTS, é possível utilizar o terminal, instalar ferramentas, desenvolver aplicações e executar serviços Linux diretamente no computador.

CONCEITO / 01 Fundamentos

O que é o WSL2?

É a segunda geração do Windows Subsystem for Linux, que utiliza um kernel Linux real em uma arquitetura de máquina virtual leve, permitindo executar distribuições Linux com integração aos recursos do Windows.

CONCEITO / 02 Distribuição

Ubuntu 26.04 LTS

É uma distribuição Linux de suporte prolongado, adequada para desenvolvimento, administração de sistemas e automação. No WSL2, fornece um ambiente Linux com gerenciador de pacotes, terminal e ferramentas próprias.

CONCEITO / 03 Requisitos

Preparação do Windows

Antes da instalação, verifique a compatibilidade da versão do Windows, a virtualização de hardware e os recursos necessários. O WSL2 depende dos componentes de virtualização disponibilizados pelo Windows.

CONCEITO / 04 Instalação

Instalar o WSL2

No PowerShell executado como administrador, utilize wsl --install para instalar os componentes necessários. Para consultar as distribuições disponíveis, utilize wsl --list --online.

CONCEITO / 05 Configuração

Selecionar o Ubuntu 26.04

Instale a distribuição identificada pelo nome disponível na listagem oficial. Caso a versão desejada esteja disponível, utilize wsl --install -d Ubuntu-26.04. O identificador deve corresponder exatamente ao nome oferecido pelo sistema.

CONCEITO / 06 Primeiro acesso

Usuário e atualização

Na primeira inicialização, configure o usuário Linux e sua senha. Em seguida, atualize os índices dos pacotes e instale as atualizações disponíveis utilizando sudo apt update e sudo apt upgrade.

CONCEITO / 07 Desenvolvimento

Ferramentas essenciais

Prepare o ambiente com ferramentas como Git, curl, build-essential e Python 3, conforme as necessidades do projeto. O APT facilita a instalação e a manutenção dos pacotes no Ubuntu.

CONCEITO / 08 Integração

Arquivos e aplicações

O WSL2 permite acessar arquivos do Windows por meio de caminhos como /mnt/c e abrir arquivos do ambiente Linux pelo Windows Explorer, utilizando explorer.exe .. Para projetos Linux, prefira armazenar os arquivos no sistema de arquivos da própria distribuição.

CONCEITO / 09 Administração

Gerenciar distribuições

Os comandos wsl --list --verbose, wsl --status e wsl --shutdown ajudam a verificar as distribuições instaladas, conferir o estado do WSL e encerrar suas instâncias em execução.

CONCEITO / 10 Manutenção

Boas práticas e segurança

Mantenha o Windows e o WSL atualizados, utilize permissões adequadas, evite executar comandos desconhecidos com privilégios administrativos e mantenha cópias de segurança dos projetos e das configurações importantes.

Fluxo de implantação do WSL2

Referência rápida de terminal

Instalar. Configurar. Desenvolver.

Os comandos abaixo ajudam a realizar as operações mais comuns de instalação, verificação e manutenção do WSL2. Os comandos wsl são executados no PowerShell ou no Prompt de Comando do Windows; os comandos apt são executados dentro do Ubuntu.

No PowerShell — como administrador:

wsl --install

Dentro do Ubuntu:

sudo apt update && sudo apt upgrade

Para verificar a versão e o estado das distribuições:

wsl --list --verbose

Observação: a disponibilidade e o nome exato da distribuição Ubuntu 26.04 dependem do catálogo apresentado pelo comando wsl --list --online. Confirme a identificação antes de executar a instalação específica.
