Formato de dados

O que é
JSON?

JSON, ou JavaScript Object Notation, é um formato leve e estruturado usado para representar e trocar dados entre sistemas. É muito utilizado em APIs porque é simples para pessoas lerem e fácil para máquinas processarem.

JSON / 01 CONCEITO

Estrutura objeto

Um objeto JSON é formado por pares de chave e valor. As chaves ficam entre aspas duplas e são separadas dos valores por dois pontos.

usuario.json object 
{
    "nome": "Ana",
    "idade": 28,
    "ativo": true
}
JSON / 02 TIPOS

Tipos de dados values

JSON possui tipos básicos como string, number, boolean, null, object e array. Eles permitem representar diferentes informações.

tipos.json values 
{
    "nome": "Carlos",
    "idade": 32,
    "admin": false,
    "telefone": null
}
JSON / 03 ARRAY

Listas array

Arrays representam listas de valores. Eles são delimitados por colchetes e seus elementos são separados por vírgulas.

produtos.json array 
{
    "produtos": [
    "Notebook",
    "Mouse",
    "Teclado"
    ]
}
JSON / 04 NESTED

Objetos aninhados nested

Um objeto pode conter outros objetos ou arrays. Isso permite representar estruturas de dados mais complexas.

cliente.json nested object 
{
    "nome": "Maria",
    "endereco": {
    "cidade": "Rio de Janeiro",
    "uf": "RJ"
    }
}
JSON / 05 API

JSON em APIs request

APIs frequentemente recebem JSON no corpo de uma requisição. Em um cadastro, por exemplo, o cliente pode enviar os dados de um novo usuário.

POST /usuarios request body 
{
    "nome": "João",
    "email": "joao@email.com",
    "idade": 25
}
JSON / 06 RESPONSE

Resposta da API response

A API também pode devolver os dados em JSON. O QA pode validar campos, valores, tipos, estrutura e regras de negócio.

HTTP 200 response body 
{
    "id": 101,
    "nome": "João",
    "ativo": true
}
JSON / 07 QA

O que testar? validation

Ao testar uma API, não basta verificar o status HTTP. Também é importante validar o JSON retornado e enviado.

Checklist QA:
✓ Campos obrigatórios
✓ Tipos de dados
✓ Valores esperados
✓ Campos extras ou ausentes
✓ Estrutura do JSON
✓ Regras de negócio
JSON / 08 ATENÇÃO

JSON válido syntax

JSON possui regras de sintaxe. Uma vírgula ou aspas colocadas incorretamente podem tornar o documento inválido.

válido.json syntax 
{
    "nome": "Ana",
    "idade": 30
}
Importante: em JSON, os nomes das propriedades devem usar aspas duplas.
