Validadores de JSON ajudam a identificar erros de sintaxe antes que o payload seja enviado ou utilizado por uma API. Eles podem apontar problemas como vírgulas, aspas, chaves ou estruturas incorretas.

JSON / 09 FERRAMENTAS

Validadores de JSON tools

Ao trabalhar com APIs, um JSON inválido pode causar erros no envio ou no processamento do payload. Antes de utilizar um JSON, podemos validar sua estrutura com ferramentas específicas.

exemplo.json invalid 
{
    "nome": "Hora do QA",
    "email": "horadoqa@test.com",
    "password": "1q2w3e4r"
    "administrador": true
}
Erro encontrado:

Invalid JSON 1 error
E009 expected ',' or '}' between object members, found a string line 5, col 5

"administrador": true

did you forget a comma after the previous value?
O problema: falta uma vírgula depois de:

"password": "1q2w3e4r"

O correto seria:

"password": "1q2w3e4r",
Ferramentas:

JSONLint — valida a sintaxe do JSON e ajuda a localizar erros no documento.

JSON Crack — permite visualizar e explorar a estrutura do JSON de forma gráfica.
