Entendendo uma API

Uma request é uma instrução enviada para uma API.
A API processa a instrução e retorna uma resposta.

Uma request ou requisição é uma mensagem enviada por uma aplicação para uma API, solicitando uma ação ou informação. Ela normalmente informa o que fazer, onde fazer e, quando necessário, quais dados enviar.
