Método HTTP

DELETE

O método DELETE é utilizado para solicitar a remoção de um recurso identificado no servidor. Neste exemplo, vamos excluir um usuário da API ServeRest.

CONCEITO / 01 REMOVE

O que é? DELETE

O DELETE solicita a remoção de um recurso. Para excluir um registro específico, normalmente informamos o identificador desse recurso na URL.

SERVEREST / 02 ENDPOINT

Excluir usuário API

O id do usuário identifica exatamente qual registro deverá ser removido.

DELETE https://serverest.dev/usuarios/0uxuPY0cbmQhpEz1
REQUEST / 03 NO BODY

Request HTTP

Para essa operação, não precisamos enviar um JSON com os dados do usuário. O id na URL é suficiente para identificar o recurso que será excluído.

DELETE /usuarios/0uxuPY0cbmQhpEz1
RESPONSE / 04 DELETED

Resposta 200 OK

Em uma exclusão realizada com sucesso, a API pode retornar uma mensagem confirmando que o registro foi excluído.

{
  "message": "Registro excluído com sucesso"
}
QA / 05 VALIDATION

O que testar? QA

Valide o status code e a mensagem retornada. Depois da exclusão, consulte o usuário novamente para confirmar que o recurso não está mais disponível.

GET /usuarios/0uxuPY0cbmQhpEz1

// Esperado:
Usuário não encontrado
QA / 06 NEGATIVE

Depois do DELETE 404

Uma boa validação é tentar acessar novamente o recurso excluído. O teste deve verificar se a API não retorna mais o usuário removido.

// Recurso removido
GET /usuarios/0uxuPY0cbmQhpEz1

// Esperado:
404 Not Found
