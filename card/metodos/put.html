Método HTTP

PUT

O método PUT é utilizado para atualizar ou substituir um recurso existente. Neste exemplo, vamos atualizar o nome de um usuário cadastrado na API ServeRest.

CONCEITO / 01 UPDATE

O que é? PUT

O PUT envia uma nova representação do recurso para o servidor. Ele é utilizado quando queremos atualizar os dados de um recurso existente.

SERVEREST / 02 ENDPOINT

Atualizar usuário API

Para atualizar um usuário específico, o id do usuário é informado na URL.

PUT https://serverest.dev/usuarios/0uxuPY0cbmQhpEz1
REQUEST / 03 BODY

Novo nome JSON

Neste exemplo, vamos atualizar o campo nome do usuário para "Hora do QA - Atualizado".

{
  "nome": "Hora do QA - Atualizado",
  "email": "horadoqa@teste.com",
  "password": "1q2w3e4r",
  "administrador": "true"
}
RESPONSE / 04 UPDATED

Resposta 200 OK

Se a atualização for realizada com sucesso, a API retorna uma resposta indicando que o registro foi alterado.

{
  "message": "Registro alterado com sucesso"
}
EXEMPLO / 05 CHANGE

Antes → Depois nome

O principal objetivo do teste é confirmar que o valor anterior foi substituído pelo novo valor enviado na requisição.

// ANTES
"nome": "Hora do QA"

// DEPOIS
"nome": "Hora do QA - Atualizado"
QA / 06 VALIDATION

O que testar? QA

Valide o status code, a mensagem retornada e, principalmente, se o usuário realmente foi atualizado. Depois do PUT, utilize um GET para confirmar o novo nome.

GET /usuarios/0uxuPY0cbmQhpEz1

// Esperado:
"nome": "Hora do QA - Atualizado"
