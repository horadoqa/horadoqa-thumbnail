Método HTTP

POST

O método POST é utilizado para enviar dados ao servidor, geralmente com o objetivo de criar um novo recurso. Neste exemplo, vamos utilizar a API ServeRest para cadastrar um novo usuário.

CONCEITO / 01 CREATE

O que é? POST

O POST envia informações para o servidor. Em APIs REST, é muito utilizado para criar novos recursos, como usuários, produtos ou pedidos.

SERVEREST / 02 ENDPOINT

Cadastrar usuário API

No ServeRest, utilizamos o endpoint /usuarios com o método POST para cadastrar um novo usuário.

POST https://serverest.dev/usuarios
REQUEST / 03 BODY

Request Body JSON

Os dados do novo usuário são enviados no corpo da requisição. O cliente informa nome, e-mail, senha e se o usuário será administrador.

{
  "nome": "Hora do QA",
  "email": "horadoqa@teste.com",
  "password": "1q2w3e4r",
  "administrador": "true"
}
RESPONSE / 04 CREATED

Resposta 201 CREATED

Após o cadastro, a API retorna uma resposta indicando que o usuário foi criado. O id é gerado pelo servidor e identifica o novo recurso.

{
  "message": "Cadastro realizado com sucesso",
  "_id": "0uxuPY0cbmQhpEz1"
}
QA / 05 VALIDATION

O que testar? QA

Ao testar o POST, valide o status code, a mensagem retornada e a criação efetiva do recurso. Também teste regras como e-mail já cadastrado, campos obrigatórios e formatos inválidos.

FLUXO / 06 TEST

O ciclo do POST API

O fluxo básico é: enviar dados → servidor processa → recurso é criado → API retorna uma resposta. Depois, o QA pode utilizar o GET para confirmar se o usuário realmente foi cadastrado.

POST /usuarios
↓
Cria usuário
↓
GET /usuarios/{id}
↓
Valida o cadastro
