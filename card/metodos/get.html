Método HTTP

GET

O método GET é utilizado para consultar recursos disponíveis em um servidor. Em APIs, é um dos métodos mais utilizados para buscar informações sem solicitar uma alteração no estado do recurso.

CONCEITO / 01 READ

O que é? GET

O GET solicita uma representação de um recurso. Ele é utilizado quando queremos consultar informações, como uma lista de usuários ou os dados de um usuário específico.

EXEMPLO / 02 REQUEST

Requisição HTTP

Imagine uma API que disponibiliza usuários. Para consultar o usuário de ID 10, podemos fazer:

GET https://serverest.dev/usuarios/0uxuPY0cbmQhpEz1
EXEMPLO / 03 RESPONSE

Resposta 200 OK

Se o usuário existir, a API pode responder com o status 200 OK e retornar os dados solicitados no corpo da resposta.

// HTTP 200 OK
{
  "nome": "Hora do QA",
  "email": "horadoqa@teste.com"
  "password": 1q2w3e4r",
  "administrador": "true",
  "id": 0uxuPY0cbmQhpEz1,
}
QA / 04 TEST

O que testar? QA

Ao testar um GET, valide principalmente o status code, corpo da resposta, estrutura dos dados, headers e tempo de resposta. Também é importante verificar como a API se comporta quando o recurso não existe.

GET /usuarios/999

// Esperado:
// HTTP 404 Not Found
EXEMPLO / 05 FILTER

Query Params filtros

O GET também pode receber parâmetros na URL para filtrar, ordenar ou paginar resultados. Eles aparecem depois do caractere ?.

GET https://serverest.dev/usuarios?administrador=true
REGRA / 06 SAFE

GET não cria consulta

Uma característica importante é que o GET é destinado à consulta. Uma requisição GET não deve ser usada para criar, editar ou excluir dados como efeito pretendido da operação.
