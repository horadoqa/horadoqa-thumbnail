Fundamentos de automação com Cypress

Seletores no Cypress —
Localizar para validar.

Os seletores permitem localizar elementos HTML para interagir com eles durante os testes automatizados. Escolher estratégias estáveis e específicas ajuda a reduzir falhas desnecessárias, aumentar a confiabilidade dos testes e facilitar a manutenção da automação.

FUNDAMENTO / 01 Conceito

O que são seletores?

São expressões utilizadas para identificar elementos da página, como campos de texto, botões, links e caixas de seleção. No Cypress, comandos como cy.get() utilizam seletores CSS para localizar esses elementos.

FUNDAMENTO / 02 Exemplo HTML

Um campo de e-mail

Um único elemento pode possuir diversos atributos que permitem sua localização. O segredo está em escolher aquele que oferece a melhor combinação de estabilidade, clareza e especificidade. 

<input
  type="email"
  data-test="username"
  id="username"
  name="username"
  placeholder="seu@email.com"
  autocomplete="email"
  required
>
SELETOR / 01 Recomendado

data-test

Atributo definido especificamente para facilitar a localização de elementos nos testes. Quando mantido estável pela equipe, reduz a dependência de alterações no layout e nas classes de estilo. 

cy.get('[data-test="username"]')

Indicação: opção preferencial para elementos que precisam ser identificados de forma consistente na automação.

SELETOR / 02 Identificação

id

Utiliza o identificador do elemento HTML. Em condições normais, o atributo deve ser único na página, permitindo uma busca direta e simples. 

cy.get('#username')

Atenção: pode ser uma boa escolha quando o identificador é estável e não depende de convenções internas sujeitas a mudanças.

SELETOR / 03 Formulários

name

Localiza elementos pelo atributo name, frequentemente utilizado em campos de formulários para identificar os dados enviados pela aplicação. 

cy.get('[name="username"]')

Indicação: alternativa útil quando o atributo é previsível, estável e identifica corretamente o campo desejado.

SELETOR / 04 Flexibilidade

Seletores CSS

Permitem localizar elementos por tag, atributo, classe, identificador e combinações de critérios. Oferecem flexibilidade, mas seletores muito dependentes da estrutura ou da apresentação podem exigir manutenção frequente. 

cy.get('input[type="email"]')

Indicação: quando os atributos disponíveis são adequados e a expressão identifica o elemento com precisão.

Comparativo dos seletores

OPÇÃO / 01

data-test

Criado para testes automatizados. Favorece a estabilidade quando sua manutenção é tratada como parte do desenvolvimento.

OPÇÃO / 02

id e name

São alternativas simples e válidas quando os atributos têm significado claro e permanecem estáveis entre versões.

OPÇÃO / 03

CSS

Oferece diferentes formas de localização. A confiabilidade depende dos critérios escolhidos e da estrutura da página.

NA PRÁTICA / 01 Interação

Localizar e interagir

Depois de localizar o campo, o Cypress pode utilizá-lo para executar ações e verificar comportamentos esperados. 

cy.get('[data-test="username"]')
  .should('be.visible')
  .type('qa@exemplo.com')
  .should('have.value', 'qa@exemplo.com')

Nesse exemplo, o teste localiza o campo, verifica sua visibilidade, digita um endereço de e-mail e confirma o valor preenchido.

Boas práticas na escolha dos seletores

PRÁTICA / 01

Priorize a estabilidade

Prefira atributos dedicados aos testes, como data-test, e estabeleça convenções consistentes com a equipe.

PRÁTICA / 02

Seja específico

Escolha critérios que identifiquem o elemento correto e evitem resultados ambíguos ou múltiplas correspondências.

PRÁTICA / 03

Evite dependências visuais

Não dependa de classes usadas apenas para estilização quando houver uma alternativa mais estável e apropriada.

ATENÇÃO / 01 Manutenção

Estabilidade não é garantia absoluta

Nenhum seletor é imune a mudanças. Um atributo data-test também pode deixar de existir ou ter seu valor alterado. A confiabilidade depende de critérios bem definidos, manutenção do código e testes que identifiquem problemas de forma clara.


Fluxo de escolha de um seletor

ETAPA / 01

Identificar

Inspecionar o HTML e identificar os atributos disponíveis no elemento que será testado.

ETAPA / 02

Selecionar

Priorizar um atributo estável e escolher um seletor CSS específico para o elemento.

ETAPA / 03

Validar

Confirmar que o elemento correto foi encontrado e verificar seu comportamento durante o teste.

Automação com confiabilidade

Localizar com precisão. Interagir com consistência. Validar com confiança.

A escolha dos seletores influencia diretamente a manutenção e a confiabilidade dos testes automatizados. Atributos estáveis, critérios específicos e convenções bem definidas ajudam a reduzir falhas causadas por mudanças na estrutura ou na aparência da aplicação.

Antes de automatizar uma interação, pergunte:

este seletor identifica o elemento certo sem depender de detalhes que podem mudar?
