Conceito de qualidade

Quando o sistema
faz algo estranho.

Nem todo comportamento inesperado aparece como uma grande falha. Às vezes, o problema surge como um pequeno comportamento visual, temporário ou intermitente. É aí que entra o conceito de glitch.

Definição

Glitch é uma anomalia geralmente pequena, inesperada ou momentânea que faz o sistema se comportar de maneira diferente do esperado.

CONCEITO / 01 VISUAL

Glitch Visual UI

Acontece quando um elemento da interface apresenta um comportamento visual inesperado, como piscar, deslocar, desaparecer ou ficar desalinhado momentaneamente.

CONCEITO / 02 INTERMITTENT

Glitch Intermitente FLAKY

Surge de maneira irregular e pode ser difícil de reproduzir. O comportamento pode acontecer em determinadas condições, tornando importante registrar contexto, ambiente, frequência e evidências.

CONCEITO / 03 RUNTIME

Glitch em Execução BEHAVIOR

O sistema funciona normalmente na maior parte do tempo, mas apresenta um comportamento inesperado durante uma ação específica, como carregamentos, transições ou processamento de dados.

CONCEITO / 04 QA ACTION

O que fazer? INVESTIGATE

Não descarte o comportamento como algo pequeno. Observe, reproduza, registre evidências e investigue as condições em que o glitch acontece. Uma pequena anomalia pode revelar um problema maior.
