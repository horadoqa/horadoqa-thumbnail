# O que é certificação CTgenAIA certificação CT-GenAI é uma certificação internacional do ISTQB (International Software Testing Qualifications Board) voltada ao uso de Inteligência Artificial Generativa em testes de software e garantia da qualidade (QA). O nome completo é Certified Tester – Testing with Generative AI. ISTQB

+1

Em termos simples, ela comprova que você conhece técnicas para usar ferramentas de IA, como ChatGPT e outros modelos de linguagem, para tornar o processo de testes de software mais eficiente e seguro.

## Para quem vale a pena?

A certificação pode ser interessante para:

- Analistas de testes e profissionais de QA.
- Engenheiros de automação de testes.
- Desenvolvedores de software.
- Líderes e gestores de qualidade.
- Profissionais de TI que querem incorporar IA aos processos de desenvolvimento e testes.

Atenção: a CT-GenAI não é uma certificação genérica para trabalhar com qualquer área de inteligência artificial. O foco é usar IA generativa no processo de testes de software.

Para conhecer o programa oficial, acesse a página do [ISTQB — CT-GenAI](<https://istqb.org/certifications/gen-ai/>).
