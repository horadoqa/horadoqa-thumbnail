Linguagem de especificação

O que é
Gherkin?

Uma linguagem estruturada e legível que transforma requisitos de negócio em cenários de comportamento — criando uma ponte comum entre produto, desenvolvimento e qualidade.

CONCEITO / 01 LANGUAGE

Gherkin specification

É uma linguagem estruturada usada para descrever o comportamento esperado de uma aplicação de maneira que pessoas técnicas e não técnicas consigam compreender.

CONCEITO / 02 BDD

BDD behavior

Gherkin é frequentemente utilizado em práticas de Behavior-Driven Development. O foco deixa de ser apenas como o sistema funciona e passa a ser qual comportamento deve acontecer.

CONCEITO / 03 KEYWORDS

Given / When / Then estrutura

Os cenários normalmente seguem uma sequência: Given define o contexto, When representa a ação e Then descreve o resultado esperado.

CONCEITO / 04 COLLABORATION

Linguagem comum shared

O principal objetivo é criar um entendimento compartilhado sobre o comportamento esperado, reduzindo ambiguidades entre negócio, desenvolvimento e QA antes mesmo da execução dos testes.

Exemplo / cenário

Um cenário Gherkin descreve uma situação real de negócio usando uma estrutura simples e próxima da linguagem humana.

Feature: Login do usuário

Scenario: Login com credenciais válidas
Given que o usuário está na tela de login
And possui credenciais válidas
When informa usuário e senha corretamente
And clica em "Entrar"
Then deve acessar a página inicial
