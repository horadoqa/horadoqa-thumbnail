Conceitos fundamentais

HTTP
vs HTTPS

Os dois protocolos são usados para transportar informações entre cliente e servidor na Web. A principal diferença está na proteção dos dados durante a comunicação.

CONCEITO / 01 STANDARD

HTTP Hypertext Transfer Protocol

É o protocolo utilizado para a comunicação entre cliente e servidor na Web. Porém, os dados são transmitidos sem criptografia. Isso significa que informações enviadas pela conexão podem ser interceptadas e lidas por terceiros.

CONCEITO / 02 SECURE

HTTPS HTTP + TLS

É o HTTP funcionando sobre uma conexão protegida por TLS. Os dados são criptografados durante o transporte, dificultando que terceiros consigam visualizar ou modificar as informações transmitidas.

CONCEITO / 03 ENCRYPTED

Criptografia confidentiality

No HTTPS, o TLS utiliza criptografia para proteger os dados durante o trânsito. Assim, uma senha, token ou informação enviada pelo navegador não é transmitida simplesmente como texto legível pela rede.

CONCEITO / 04 IDENTITY

Certificado digital / TLS

O certificado digital ajuda o navegador a validar a identidade do servidor e participa do estabelecimento da conexão segura. É por isso que o navegador pode indicar que um site está utilizando uma conexão HTTPS válida.
