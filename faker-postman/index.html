Dados dinâmicos no Postman

Faker no
Postman ???

Sim !!! O Postman possui as chamadas Dynamic Variables, que funcionam de forma muito parecida com o Faker. Elas permitem gerar dados aleatórios automaticamente durante a execução de uma requisição.

CONCEITO / 01 DYNAMIC VARIABLES

Dynamic Variables faker-like

O Postman oferece variáveis dinâmicas para criar dados aleatórios sem precisar cadastrar manualmente cada valor. Elas são especialmente úteis para testes de API, massas de dados e automação de cenários.

{{$randomFirstName}}
{{$randomEmail}}
{{$randomUUID}}
{{$timestamp}}
CONCEITO / 02 SCRIPTS

Também em scripts pm.variables

As Dynamic Variables também podem ser utilizadas dentro dos scripts do Postman. Para isso, é possível utilizar pm.variables.replaceIn() para substituir a variável dinâmica pelo valor gerado.

JavaScript Postman Script 
pm.variables.replaceIn('{{$randomFirstName}}')

Existem mais de 100 variáveis disponíveis, cobrindo diferentes tipos de dados.

EXEMPLO / 01 JSON

Gerando uma pessoa request body

Basta colocar as Dynamic Variables diretamente no corpo JSON da requisição.

JSON POST /users 
{
  "nome": "{{$randomFullName}}",
  "cargo": "{{$randomJobTitle}}"
}

EXEMPLO / 02 JSON

Gerando acesso request body

Um único request pode receber dados diferentes a cada execução, sem a necessidade de alterar manualmente o payload.

JSON POST /users 
{
  "email": "{{$randomEmail}}",
  "username": "{{$randomUserName}}"
}
CATEGORIA / 04 IDENTIFIERS

Identificadores e timestamps system

O Postman também oferece variáveis para gerar identificadores únicos e informações relacionadas a data e hora.

{{$guid}}
{{$timestamp}}
{{$isoTimestamp}}
{{$randomUUID}}

Por que isso é útil?
Você consegue criar massas de dados diferentes a cada execução, reduzindo dados fixos nos testes e facilitando cenários de automação de APIs.
