# Skill: Identidade Visual

 ## Objetivo

 Esta skill define a identidade visual padrão para todos os projetos relacionados ao canal e às suas peças de comunicação visual.

 Toda thumbnail, capa, composição gráfica, arte editorial ou interface visual criada dentro de um projeto que utilize esta skill deve seguir estas diretrizes, salvo instrução explícita em contrário.

 A identidade deve transmitir:

 - Credibilidade
- Personalidade
- Precisão
- Sofisticação
- Caráter editorial
- Linguagem técnica
- Humanidade

 O resultado **não deve parecer uma marca genérica de tecnologia**.

 A direção visual combina **editorial + técnico + humano**, utilizando verde profundo, tipografia editorial e elementos inspirados em interfaces, relatórios, testes e documentação.

---

 # 1\. Princípio central

 ## Menos sinal, mais significado.

 A identidade não deve depender de excesso de elementos, efeitos ou cores chamativas.

 Cada elemento visual precisa ter uma função.

 O **verde-sinal `#8FE3B0`** representa:

 - Confirmação
- Aprovação
- Descoberta
- Informação importante
- Resultado
- Status positivo
- Insight

 Ele deve ser usado de maneira pontual.

 **Nunca transformar o verde-sinal na cor dominante da composição.**

 Quanto mais raro o verde-sinal, maior será sua capacidade de chamar atenção.

---

 # 2\. Personalidade visual

 A direção deve equilibrar três características.

 ### Editorial

 Transmitir:

 - Publicação
- Ensaio
- Jornalismo
- Autoridade
- Curadoria
- Personalidade autoral

 Recursos:

 - Tipografia serifada
- Itálico
- Contraste tipográfico
- Espaços de respiro
- Composição assimétrica quando apropriado
- Hierarquia visual clara

 ### Técnica

 Transmitir:

 - Sistemas
- Testes
- Código
- Documentação
- Dados
- Processos
- Engenharia

 Recursos:

 - Tipografia monoespaçada
- Tags
- Labels
- Status
- IDs
- Versões
- Linhas
- Divisores
- Pequenos elementos de interface
- Referências visuais a terminal, relatório e documentação

 ### Humana

 Transmitir:

 - Autoria
- Curiosidade
- Imperfeição controlada
- Naturalidade
- Personalidade

 Evitar:

 - Estética excessivamente corporativa
- Visual de SaaS genérico
- Gradientes neon
- Excesso de glow
- Composições excessivamente perfeitas
- Aparência de template tecnológico

---

 # 3\. Paleta de cores

 | Nome | Hex | Função |
| --- | --- | --- |
| Verde profundo | `#0F3D2E` | Cor estrutural e principal |
| Verde-musgo | `#3F6F52` | Apoio e variações secundárias |
| Verde-sinal | `#8FE3B0` | Destaques, status e informações importantes |
| Dourado | `#C99A44` | Contraponto sofisticado e detalhes especiais |
| Marfim | `#F3EFE6` | Fundo claro e áreas de respiro |
| Tinta | `#12201A` | Texto, fundo escuro e alto contraste |

## Hierarquia de uso

 ### 1\. Verde profundo — `#0F3D2E`

 É a principal cor estrutural da identidade.

 Usar em:

 - Fundos
- Blocos
- Áreas estruturais
- Molduras
- Grandes superfícies
- Elementos principais

 ### 2\. Tinta — `#12201A`

 Usar para:

 - Textos escuros
- Fundos de alto contraste
- Elementos técnicos
- Áreas de profundidade

 ### 3\. Marfim — `#F3EFE6`

 Usar para:

 - Fundos claros
- Textos sobre fundos escuros
- Áreas de respiro
- Composições editoriais

 ### 4\. Verde-musgo — `#3F6F52`

 Usar como:

 - Cor intermediária
- Elemento secundário
- Divisor
- Bloco auxiliar
- Variação do verde principal

 ### 5\. Verde-sinal — `#8FE3B0`

 Usar exclusivamente para:

 - Status
- Destaques
- Resultados
- Pequenos elementos importantes
- Indicadores
- Informações que precisam chamar atenção

 **Evitar grandes áreas preenchidas com verde-sinal.**

 ### 6\. Dourado — `#C99A44`

 Usar como contraponto.

 Pode aparecer em:

 - Pequenos detalhes
- Linhas
- Marcadores
- Elementos especiais
- Informações premium/editoriais
- Pequenos acentos tipográficos

 O dourado não deve competir com o verde-sinal.

---

 # 4\. Combinações preferenciais

 ## Modo escuro

 Priorizar:

```
#0F3D2E
#12201A
#F3EFE6
#8FE3B0
#C99A44
```

 Uma composição escura deve parecer **orgânica e editorial**, e não cyberpunk ou neon.

 ### Combinação recomendada

```
Fundo:       #0F3D2E
Texto:       #F3EFE6
Detalhes:    #3F6F52
Sinal:       #8FE3B0
Acento:      #C99A44
```

---

 # 5\. Modo claro

 Priorizar:

```
#F3EFE6
#0F3D2E
#12201A
#3F6F52
#8FE3B0
```

 ### Combinação recomendada

```
Fundo:       #F3EFE6
Título:      #0F3D2E
Texto:       #12201A
Apoio:       #3F6F52
Sinal:       #8FE3B0
```

 O modo claro deve parecer uma **versão editorial clara da mesma identidade**, nunca uma identidade diferente.

---

 # 6\. Tipografia

 A identidade utiliza três famílias tipográficas.

 ## Newsreader Italic

 ### Função

 Títulos e wordmark.

 ### Característica

 Serifada editorial, autoral e humana.

 Seu uso em itálico é importante para criar contraste com a estética tradicional de marcas de tecnologia.

 ### Prioridade

 Usar principalmente em:

 - Títulos principais
- Palavras-chave
- Frases de impacto
- Wordmark
- Destaques editoriais

 Exemplo conceitual:

```
The future
is different.
```

 ou

```
What
changed?
```

 A tipografia deve ter presença e personalidade.

---

 # 7\. JetBrains Mono

 ### Função

 Elementos técnicos.

 Usar em:

 - Status
- Tags
- Metadados
- IDs
- Versões
- Códigos
- Pequenos labels
- Indicadores
- Dados
- Informações de sistema

 Exemplos:

```
STATUS: PASS
```

```
BUILD: 042
```

```
TESTED
```

```
VERSION: 2.4.1
```

```
RESULT: VERIFIED
```

 A JetBrains Mono deve funcionar como uma **camada de informação técnica**, e não como a fonte principal da composição.

---

 # 8\. Manrope

 ### Função

 Corpo e informações secundárias.

 Usar em:

 - Textos auxiliares
- Subtítulos
- Descrições
- Informações explicativas
- Interface
- Pequenos blocos de texto

 A Manrope equilibra a personalidade da Newsreader com a linguagem técnica da JetBrains Mono.

---

 # 9\. Hierarquia tipográfica

 A hierarquia preferencial é:

```
NEWSREADER ITALIC
        ↓
Título / ideia principal

MANROPE
        ↓
Contexto / explicação

JETBRAINS MONO
        ↓
Status / dados / metadados
```

 Não utilizar as três fontes indiscriminadamente.

 Cada família deve possuir uma função clara.

---

 # 10\. Linguagem de thumbnails

 Uma thumbnail deve comunicar a ideia principal rapidamente.

 Priorizar:

 - Uma ideia central
- Poucos elementos
- Forte hierarquia
- Alto contraste
- Tipografia expressiva
- Um ponto focal
- Elementos técnicos pequenos
- Composição editorial

 Evitar:

 - Excesso de texto
- Muitos elementos competindo
- Excesso de badges
- Muitos ícones
- Excesso de linhas
- Gradientes tecnológicos genéricos
- Neon
- Glow exagerado
- Visual de dashboard
- Visual excessivamente corporativo

---

 # 11\. Elementos técnicos

 Elementos técnicos podem ser utilizados como linguagem visual.

 Exemplos:

```
STATUS: PASS
```

```
BUILD 042
```

```
TESTED
```

```
VERIFIED
```

```
v2.4.1
```

```
CASE_07
```

```
RESULT: 98%
```

```
SYSTEM CHECK
```

 Esses elementos devem parecer **informações reais de um sistema ou relatório**, mesmo quando utilizados de maneira puramente estética.

 Não adicionar elementos técnicos sem função visual.

---

 # 12\. Status e sinalização

 O conceito de status é uma parte importante da identidade.

 O sistema visual pode utilizar:

```
PASS
TESTED
VERIFIED
NEW
UPDATED
FOUND
RESULT
```

 O status deve ser pequeno e secundário em relação ao conceito principal da thumbnail.

 Quando representar aprovação ou confirmação, preferir:

```
STATUS: PASS
```

 com `#8FE3B0` aplicado de forma pontual.

---

 # 13\. Composição

 Priorizar composição com:

 - Assimetria controlada
- Espaços negativos
- Contraste de escala
- Hierarquia clara
- Grandes blocos de cor
- Pequenos elementos técnicos
- Tipografia editorial como elemento gráfico

 Uma boa composição pode conter:

```
[ pequeno label técnico ]

        GRANDE
        TÍTULO
        editorial

                [ elemento visual ]

[ pequeno metadado ]
```

 Não é necessário preencher toda a área disponível.

 O espaço vazio faz parte da identidade.

---

 # 14\. Contraste

 O contraste deve ser construído principalmente através de:

 ### Cor

 Verde profundo × Marfim

 ### Tipografia

 Serifada × Monoespaçada

 ### Escala

 Grande título × Pequenos metadados

 ### Densidade

 Grande área limpa × Pequenos elementos técnicos

 ### Forma

 Composição editorial × elementos de interface

---

 # 15\. Fotografia e imagens

 Quando fotografias ou pessoas forem utilizadas:

 - Priorizar aparência natural
- Evitar tratamento excessivamente artificial
- Evitar estética de stock photo
- Manter contraste compatível com a paleta
- Utilizar a fotografia como elemento principal quando ela for relevante
- Não sobrecarregar a imagem com elementos gráficos

 A identidade deve continuar reconhecível mesmo quando a fotografia mudar.

---

 # 16\. Tratamento de imagens

 Quando necessário, a imagem pode receber:

 - Tonalização verde sutil
- Contraste moderado
- Escurecimento localizado
- Granulação discreta
- Recortes editoriais
- Máscaras simples

 Evitar:

 - Filtros neon
- Duotones excessivamente fortes
- Glow artificial
- Efeitos futuristas genéricos
- Excesso de blur
- Tratamentos que destruam a naturalidade da fotografia

---

 # 17\. Bordas, linhas e divisores

 Linhas finas podem ser utilizadas para reforçar a linguagem de relatório/interface.

 Preferir:

 - Linhas discretas
- Divisores horizontais
- Pequenas molduras
- Boxes simples
- Marcadores técnicos

 As linhas devem apoiar a composição, não dominar a imagem.

---

 # 18\. Ícones e símbolos

 Ícones devem ser simples e funcionais.

 Priorizar:

 - Símbolos geométricos
- Indicadores
- Checkmarks
- Pontos
- Pequenos marcadores
- Elementos de interface

 Evitar:

 - Ícones 3D
- Ícones excessivamente detalhados
- Emojis como elemento principal
- Ilustrações genéricas de tecnologia
- Ícones neon

---

 # 19\. O que NÃO fazer

 A identidade não deve evoluir para:

 ### Cyberpunk

 Evitar:

 - Neon
- Roxo
- Azul elétrico
- Glow
- Grid futurista

 ### SaaS genérico

 Evitar:

 - Gradientes roxo/azul
- Cards excessivos
- Ilustrações corporativas
- Ícones genéricos
- Layout de landing page

 ### Gaming

 Evitar:

 - Explosões
- Flares
- Tipografia agressiva
- Contornos exagerados
- Saturação extrema

 ### Minimalismo vazio

 A identidade também não deve ser tão minimalista a ponto de perder personalidade.

 A composição precisa manter a combinação:

 **editorial + técnico + humano.**

---

 # 20\. Regra de destaque

 Antes de adicionar um destaque visual, perguntar:

 > "O que exatamente esse destaque significa?"

 Se a resposta for "apenas para ficar bonito", provavelmente ele não deve existir.

 Especialmente para o verde-sinal:

```
#8FE3B0 = atenção
```

 Não:

```
#8FE3B0 = decoração
```

---

 # 21\. Regra de consistência

 Todos os projetos devem parecer partes do mesmo universo visual.

 Mesmo quando:

 - O tema mudar
- A fotografia mudar
- O assunto mudar
- O fundo mudar
- A composição mudar

 Devem permanecer reconhecíveis:

 - A paleta
- A relação entre editorial e técnico
- A tipografia
- O tratamento dos sinais
- A contenção visual
- O caráter autoral

---

 # 22\. Checklist obrigatório

 Antes de finalizar qualquer peça, verificar:

 ### Identidade

 - [ ] A peça parece pertencer à mesma identidade visual?
- [ ] Verde profundo está presente de maneira estrutural ou contextual?
- [ ] A composição evita aparência genérica de tecnologia?

 ### Tipografia

 - [ ] Newsreader Italic está sendo usada para personalidade/editorial?
- [ ] JetBrains Mono está restrita a informações técnicas?
- [ ] Manrope está sendo usada para informações secundárias?
- [ ] Existe hierarquia tipográfica clara?

 ### Cor

 - [ ] O verde-sinal `#8FE3B0` está sendo usado com parcimônia?
- [ ] O dourado `#C99A44` não está competindo com o verde-sinal?
- [ ] Existe contraste suficiente?
- [ ] A composição funciona em fundo claro ou escuro conforme necessário?

 ### Composição

 - [ ] Existe um ponto focal?
- [ ] A ideia principal é compreendida rapidamente?
- [ ] Existe espaço negativo suficiente?
- [ ] Os elementos técnicos são secundários?
- [ ] Nada está sendo adicionado apenas como decoração?

 ### Resultado

 - [ ] Parece sofisticado?
- [ ] Parece técnico?
- [ ] Parece humano?
- [ ] Parece autoral?
- [ ] Evita estética genérica de "tech brand"?

---

 # 23\. Regra final

 Quando houver dúvida entre adicionar mais elementos ou remover elementos:

 **remover.**

 Quando houver dúvida entre usar uma cor chamativa ou manter a paleta:

 **manter a paleta.**

 Quando houver dúvida entre destacar tudo ou destacar uma coisa:

 **destacar uma coisa.**

 Quando houver dúvida entre parecer "tecnológico" ou parecer "editorial + técnico + humano":

 **escolher editorial + técnico + humano.**

 A identidade deve ser reconhecida não pela quantidade de elementos, mas pela **coerência entre cor, tipografia, composição e significado**.

 > **Menos sinal, mais significado.**

 Se quiser, também posso transformar isso em uma **skill mais completa para agentes de IA**, incluindo `SKILL.md` \+ estrutura de pastas + regras de execução + exemplos de prompts \+ critérios para geração de thumbnails.
